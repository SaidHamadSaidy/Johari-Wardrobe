# Johari Market: your files

| File | What it is |
|---|---|
| index.html | The Johari Market store (your home page) |
| business.html | The Johari Business website |
| admin.html | Johari Operations: orders, products, customers, settings |
| products.json | Your products (edit them from admin.html) |
| config.json | WhatsApp number, Lipa Namba, delivery fees (edit from admin.html) |

Hosting: the files live in your GitHub repository `johari-market`, and Cloudflare Pages publishes them for free (commercial use allowed).
Orders are saved in a separate private repository, `johari-orders`, so customer details stay private.
Product photos you upload in the admin are saved in an `images` folder automatically.

Your addresses after setup (Cloudflare shows the exact address when you finish):
- Store: https://johari-market.pages.dev/
- Business website: https://johari-market.pages.dev/business.html
- Operations: https://johari-market.pages.dev/admin.html

Keep your access key safe: enter it only in admin.html on your own devices, never in chats or emails.
